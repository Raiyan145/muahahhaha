GOAT LUFFY — PERSONAL WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser (Chrome, Edge, Firefox).
3. Drag the stone backward from the slingshot and release it toward the hanging glass lamp.
4. Once the glass is hit, the portfolio is revealed.

NOTES
- The intro uses a canvas-based slingshot interaction with gravity, lamp swing, glass particles and sound toggle.
- The site is responsive and includes your supplied Luffy profile image and nine supplied photographs.
- Social details: Facebook, Discord and GitHub links are configured. Instagram is displayed as “BOLBO NA” because no profile URL/username was supplied.
- The profile information is editable in index.html and social links in app.js.
- For best results, run with a local static server (e.g. VS Code Live Server) rather than opening as a file.
